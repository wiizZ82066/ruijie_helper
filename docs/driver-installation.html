准备有线连接

仅使用 JNU 无线？无需安装这个驱动，可以直接返回助手登录。
助手提示“有线驱动已就绪”？也不需要重复安装。

有线认证需要一个名为 Npcap 的网络驱动。本程序可以检测它，但不会替你下载或安装。独立有线认证不需要安装锐捷客户端。

按这三步操作

  1. 打开 Npcap 官方下载页，选择 Npcap installer。不要选 SDK、源代码或调试符号。下载后打开安装文件。
  2. 确认 Windows 管理员提示，阅读许可并按向导继续。保留 Install Npcap in WinPcap API-compatible Mode（兼容模式）选项；本助手无需开启无线监听模式。已有 WinPcap 时，兼容模式可能替换它，请阅读安装器提示。
  3. 安装结束后回到助手，打开“设置 → 环境检测与驱动说明”，点击重新检测。显示驱动就绪后再连接校园网；若安装器要求重启，先保存工作并重启电脑。

目前没有网络怎么办？

可以临时连接手机热点访问官网，或在另一台联网电脑上下载官方安装文件，再用 U 盘复制过来。这份说明本身不需要联网。

安装后仍提示异常？

  • 先完成安装或按提示重启，再重新检测；不要同时打开多个驱动安装向导。
  • 提示权限不足：退出助手，再右键“以管理员身份运行”。
  • 提示暂未发现接口：检查网卡是否启用、网线是否插好，再重新检测。这不等于一定没安装驱动。
  • 驱动就绪仅表示底层组件可加载并能读取接口，校园网账号认证仍需实际连接确认。
