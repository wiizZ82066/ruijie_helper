校园网认证助手 Flet 版使用说明

开始使用
发布包名称为 CampusAuthenticatorFlet-win-x64.zip。完整解压后，运行 CampusAuthenticatorFlet 文件夹内的 CampusAuthenticatorFlet.exe，并保留旁边的 _internal 文件夹及其他文件。不要只复制 EXE，也不要从压缩包中直接运行。
目录版启动时无需再次解压运行库。请完整保留发布包中的所有文件。
本程序需要 Windows。有线默认使用独立认证，需要兼容的抓包驱动，无需启动锐捷客户端；JNU 无线登录也由本程序独立完成。移动热点另外需要无线网卡支持。启动时请允许管理员提示。

连接方式
程序自动选择连接方式，有线优先，无需手动选择网卡。有多张可用的实体有线网卡时，优先沿用仍连接的网卡，否则按稳定顺序选择；原网卡拔出后可以选择另一张已连接的网卡。没有有线链路时连接已保存的 JNU 无线配置，再完成网页认证。首次请在 Windows 中连接一次 JNU，让系统保存配置。JNU-Secure 使用不同认证方式，不属于本次无线支持范围。
开启“运行后自动连接”后，程序监测稳定的链路变化，并在唤醒后重新确认连接。短暂断线、认证超时或取址失败最多自动重试三次，账号密码被拒绝后停止重试。手动断开后不会自动连回，需再次点击连接。编辑中的账号不会由后台自动提交；修改后请点击一次“连接校园网”。该功能选择认证接口，不修改系统路由、DNS 或 Clash 配置。
无线请求绑定到实际 Wi-Fi 网卡及其 DNS，避免使用 Clash 的虚拟 DNS 地址。仅向学校已验证证书的 HTTPS 认证地址提交账号；会分别检查服务器在线状态和无线出口连通性。需要验证码或额外服务选择的页面会停止自动登录并提示。
无线模式不安装或启动原生认证核心，也不写原生账号配置。选择“使用原客户端保存的账号”时，仅为读取凭据而需要原客户端；手动输入或 DPAPI 保存的账号不需要它。自动热点仅随有线登录开启。

有线连接校园网
1. 默认使用“独立认证”，无需启动或安装锐捷客户端。先接入实体有线网卡，再输入账号密码并点击“连接校园网”；也可从本机锐捷导入一次账号。
2. 独立认证需要已安装的 WinPcap，或启用 WinPcap API 兼容模式的 Npcap。程序不自动安装驱动。卸载锐捷时请确认没有同时删除仍在使用的抓包驱动。
3. 设置中保留“有线认证方式”，服务自动使用 internet，有线网卡自动选择。路径和网卡标识不固定为开发机器。
4. 程序自行完成 EAP-MD5 和必要扩展，并分别判断认证成功与实际有线出口联网。成功后主按钮变为“断开校园网”。断开或从托盘退出会结束本程序的有线会话；收起到托盘保持连接。
5. 仍运行着已核验的旧客户端时，会临时停止其核心和守护服务，避免同时认证；不修改文件或服务启动类型。初次独立认证失败时尝试恢复旧客户端。未知版本或原客户端界面仍打开时，请先退出原客户端。
6. 当前实现按服务端返回的关闭状态处理传统心跳。如果服务器要求尚未支持的保活方式，会明确提示切换“兼容认证”，不会把它显示为持续联网成功。
7. 兼容认证仍使用已核验的原锐捷核心，需要原客户端目录，可能进行原有备份和兼容安装。该路径保留供独立模式不适用时使用。

记住账号与自动启动
导入只读取原客户端配置，不修改配置或重启认证。仅支持已核验的客户端版本和本机保存的密码；未保存密码、配置损坏或无法解密时可手动输入。导入成功不代表认证成功，仍需点击连接。再次导入会替换本程序已保存的账号；启动时不会自动覆盖。导入后自动退出“使用原客户端保存的账号”兼容模式，下次启动可使用加密保存的凭据自动连接。
“记住账号密码”使用 Windows 当前用户 DPAPI，将账号和密码一起加密保存在本程序的数据目录中。未勾选时，本程序不保存自己的这份凭据。
如需自动连接，在“设置”→“常规”勾选“运行后自动连接”和“登录 Windows 后自动启动”。自启动任务在当前用户登录 Windows 约 30 秒后运行。程序没有可用的账号密码时会停留在输入界面。
“使用原客户端保存的账号”会读取本机锐捷当前账号及其保存的密码，随后执行认证并等待本次会话结果；不另存到本程序凭据库。原客户端未保存密码或配置不受支持时，会提示手动输入。
自启动及“运行后自动连接”自动选择可用的有线网卡，无有线连接时尝试 JNU。这项检查不要求网卡已经能上网，也不会把 Wi-Fi、Clash 虚拟网卡或已识别的手机 USB 共享网卡当作校园有线接入。冷启动时，若认证成功但尚无网络地址，会仅对当前有线网卡限次申请 DHCP 地址，等地址、网关和 DNS 就绪后继续认证。
自启动状态显示未知时，不代表已经开启或关闭；以设置页的操作结果为准。移动程序文件夹后，请重新设置自启动，使任务指向新位置。

账号保存范围
记住选项只控制本程序的 DPAPI 加密库。独立有线和无线认证均不写锐捷账号配置。只有选择“兼容认证”时，原生核心才需要自己的 DES 兼容配置及账号目录。
因此，未勾选记住或清除本程序保存的账号，不等于删除原客户端记录，也不能理解为整个登录链路没有明文账号标识。
“设置”→“维护”中的“清除保存的账号”只清除本程序凭据库。保存的凭据无法解锁时，程序保留原文件并拒绝覆盖；可在此明确清除后重新输入。

个人热点与 Clash/Mihomo TUN
在独立的“热点”页面设置名称、密码和频段，用同一个按钮开启或关闭热点。默认名称为 ovo，默认密码为 12345678；已有设置优先。密码可切换显示。
热点页也可勾选“连接成功后自动开启热点”。有线网卡自动选择。“保存设置”只保存配置，已开启热点的新名称与密码将在下次开启时生效。
存在唯一可用的 Clash/Mihomo TUN 时，程序自动使用其共享来源，并明确选择热点无线设备。没有活动 TUN 时使用所选有线网络。来源不明确、缺少必要连接或存在多张无法区分的无线设备时，程序会停止开启并提示原因。
热点检查支持经典 ICS 共享配对和本程序明确启动的现代 WinRT 会话；旧式 COM 标志为空不一定代表失败，但实际来源冲突、状态读取失败或外部已有热点不能据此假报成功。
“热点已开启”不等于手机已经联网。请确认手机成功获取地址，并实际打开网页。Windows 版本、无线驱动和网络策略会影响结果。
开启失败时，程序只在能确认属于本次启动时尝试恢复原状态。若提示无法确认热点关闭，请使用 Windows 的“移动热点”设置查看或关闭。

设置与恢复
“设置”集中展示以下功能，运行记录默认折叠：
常规：有线认证方式、自动连接和登录自启动。切换到锐捷兼容认证后才显示客户端目录配置。
热点页面：热点名称、密码、频段和认证成功后自动开热点。
维护：检查网络、恢复原版、清除本程序保存的账号和诊断记录。
“恢复原版”恢复已校验的认证核心，并尝试关闭本程序的登录自启动；原版限制也会恢复。关闭自启动失败时会在维护记录中说明。
“恢复原版”不会自动清除原客户端的账号记录。账号配置写入失败时会尝试在当前进程内回滚；进程被强制结束或突然断电后的原生配置恢复不在本版本保证范围内。

数据与公开分享
当前用户的数据目录为 %APPDATA%\CampusLogin。核心备份和恢复记录需要保留。
settings.json 含热点密码；credentials.dpapi 是本程序的加密账号库。原客户端目录含其自己的账号配置。
不要公开上述文件、原生用户目录、个人诊断记录或带有账号信息的截图。诊断可能包含网卡名称、接口标识、网络地址与本机路径。
本项目的公开说明不包含个人账号配置或真实现场报告。

适用范围
独立有线已在当前校园网通过两轮认证和短时持续联网测试；不保证其他学校采用相同策略。目前仅支持 ASCII 账号密码。无地址时会在首轮成功后向所选网卡申请 DHCP 地址，再完成下一轮认证；冷启动、拔插、睡眠唤醒仍需现场验证。服务器发起重新认证时有频率限制，账号被拒绝后不会无限重试。兼容认证仅支持已核验的 RG-SU 6.61 文件；无线按 JNU 当前网页接口实现。
兼容修改处理已定位的本地多网卡、共享和代理检查，正常认证及心跳仍由原核心执行，不依赖登录后结束或移走认证组件。
无法保证服务器端不识别共享，也不保证所有系统、无线驱动或长期运行情况相同。离线测试不能替代真实认证和终端联网检查。

界面与版本切换
校园网、热点和设置分为三个独立页面。宽窗口使用侧边导航，窄窗口自动改用顶部导航；页面可滚动查看，输入框随可用宽度变化。
热点和自启动状态在后台独立读取，主界面不需要等待这些查询全部完成才能输入或连接。首次运行的系统检查和认证本身仍需要时间。
关闭窗口时，若托盘可用则收起到托盘；从托盘选择退出会等待当前操作安全结束。
Flet 版和原 Qt 版共用配置与加密账号库，并通过单实例锁避免同时操作。切换版本后，请在准备长期使用的版本中重新启用自启动。
程序启动时使用随包校验的桌面运行时，不会下载或安装依赖。请完整保留发布包文件。
