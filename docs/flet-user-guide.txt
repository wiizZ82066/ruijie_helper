校园网认证助手 Flet 版使用说明

开始使用
发布包名称为 CampusAuthenticatorFlet-win-x64.zip。完整解压后，运行 CampusAuthenticatorFlet 文件夹内的 CampusAuthenticatorFlet.exe，并保留旁边的 _internal 文件夹及其他文件。不要只复制 EXE，也不要从压缩包中直接运行。
目录版启动时无需再次解压运行库。请完整保留发布包中的所有文件。
本程序需要 Windows、已安装的受支持锐捷客户端和驱动，以及支持移动热点的无线网卡。启动时请允许管理员提示，并保留锐捷原安装目录。

连接校园网
1. 程序自动查找客户端安装目录。未找到时，在导航中的“设置”→“常规”使用“自动查找”或“选择目录”；不要求固定盘符。
2. 主界面输入校园账号和密码，点击“连接校园网”。密码旁可切换“显示/隐藏”。
3. 首次连接会校验并备份原认证核心，再安装兼容修改。准备账号时会短暂重启认证服务，网络可能短暂中断。
4. 程序等待本次核心会话的新认证结果；暂时失败时继续等待原核心自行完成连接，不把旧的成功结果算作本次成功。原客户端未更新结果文件时，程序会检查当前会话新产生的明确认证日志事件，避免已经认证成功却一直显示连接中。
5. 此版本沿用原客户端的网卡、认证方式等配置。若提示缺少可复用的用户配置，请先在原客户端完成这些配置。

记住账号与自动启动
“记住账号密码”使用 Windows 当前用户 DPAPI，将账号和密码一起加密保存在本程序的数据目录中。未勾选时，本程序不保存自己的这份凭据。
如需自动连接，在“设置”→“常规”勾选“运行后自动连接”和“登录 Windows 后自动启动”。自启动任务在当前用户登录 Windows 约 30 秒后运行。程序没有可用的账号密码时会停留在输入界面。
“使用原客户端中保存的账号”是单独的兼容选项，启用后沿用原客户端设置，必要时在其登录窗口完成连接。
自启动状态显示未知时，不代表已经开启或关闭；以设置页的操作结果为准。移动程序文件夹后，请重新设置自启动，使任务指向新位置。

账号保存范围
记住选项只控制本程序的 DPAPI 加密库。现有认证核心仍需要原生账号配置：密码以其 DES 兼容格式保存，原生用户目录和配置中保留可辨识的账号。
因此，未勾选记住或清除本程序保存的账号，不等于删除原客户端记录，也不能理解为整个登录链路没有明文账号标识。
“设置”→“维护”中的“清除保存的账号”只清除本程序凭据库。保存的凭据无法解锁时，程序保留原文件并拒绝覆盖；可在此明确清除后重新输入。

个人热点与 Clash/Mihomo TUN
主界面可以设置热点名称和密码，用同一个按钮开启或关闭热点。默认名称为 ovo，默认密码为 12345678；已有设置优先。密码可切换显示。
在“设置”→“网络与热点”选择实际连接校园网的“有线网络”、频段，或勾选“连接成功后自动开启热点”。“保存设置”只保存配置，已开启热点的新名称与密码将在下次开启时生效。
存在唯一可用的 Clash/Mihomo TUN 时，程序自动使用其共享来源，并明确选择热点无线设备。没有活动 TUN 时使用所选有线网络。来源不明确、缺少必要连接或存在多张无法区分的无线设备时，程序会停止开启并提示原因。
热点检查支持经典 ICS 共享配对和本程序明确启动的现代 WinRT 会话；旧式 COM 标志为空不一定代表失败，但实际来源冲突、状态读取失败或外部已有热点不能据此假报成功。
“热点已开启”不等于手机已经联网。请确认手机成功获取地址，并实际打开网页。Windows 版本、无线驱动和网络策略会影响结果。
开启失败时，程序只在能确认属于本次启动时尝试恢复原状态。若提示无法确认热点关闭，请使用 Windows 的“移动热点”设置查看或关闭。

设置与恢复
“设置”集中展示以下功能，运行记录默认折叠：
常规：客户端目录、自动连接、原客户端账号兼容方式和登录自启动。
网络与热点：频段、有线网络和认证成功后自动开热点；名称和密码在主页修改。
维护：检查网络、恢复原版、清除本程序保存的账号和诊断记录。
“恢复原版”恢复已校验的认证核心，并尝试关闭本程序的登录自启动；原版限制也会恢复。关闭自启动失败时会在维护记录中说明。
“恢复原版”不会自动清除原客户端的账号记录。账号配置写入失败时会尝试在当前进程内回滚；进程被强制结束或突然断电后的原生配置恢复不在本版本保证范围内。

数据与公开分享
当前用户的数据目录为 %APPDATA%\CampusLogin。核心备份和恢复记录需要保留。
settings.json 含热点密码；credentials.dpapi 是本程序的加密账号库。原客户端目录含其自己的账号配置。
不要公开上述文件、原生用户目录、个人诊断记录或带有账号信息的截图。诊断可能包含网卡名称、接口标识、网络地址与本机路径。
本项目的公开说明不包含个人账号配置或真实现场报告。

适用范围
本程序复用原锐捷核心和驱动，仅支持代码中已核验的 RG-SU 6.61 文件；它不是独立重写的校园网认证协议。自动发现目录不代表支持任意版本。
兼容修改处理已定位的本地多网卡、共享和代理检查，正常认证及心跳仍由原核心执行，不依赖登录后结束或移走认证组件。
无法保证服务器端不识别共享，也不保证所有系统、无线驱动或长期运行情况相同。离线测试不能替代真实认证和终端联网检查。

界面与版本切换
窗口较宽时登录与热点并排显示，较窄时自动上下排列并改用顶部导航；设置页可滚动查看。输入框会随卡片宽度变化。
热点和自启动状态在后台独立读取，主界面不需要等待这些查询全部完成才能输入或连接。首次运行的系统检查和认证本身仍需要时间。
关闭窗口时，若托盘可用则收起到托盘；从托盘选择退出会等待当前操作安全结束。
Flet 版和原 Qt 版共用配置与加密账号库，并通过单实例锁避免同时操作。切换版本后，请在准备长期使用的版本中重新启用自启动。
程序启动时使用随包校验的桌面运行时，不会下载或安装依赖。请完整保留发布包文件。
